# PaperPilot Website

Marketing and distribution site for PaperPilot: the landing page, docs, and download links.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.

## Build

```bash
npm run build
```

This produces a static export (`output: "export"` in `next.config.ts`) — the site has no server-side runtime and can be hosted from any static file host.

## Tests

```bash
npm run test
```

## Lint

```bash
npm run lint
```
